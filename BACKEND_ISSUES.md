1  Notifications Push Intelligentes via ntfy

Le backend .NET utilise déjà ntfy (https://ntfy.winplus.cm). Crée un service SmartNotificationService.cs qui génère des notifications personnalisées via WinAI plutôt que des messages génériques. Avant chaque notification, appelle POST /api/ai/generate-notification (Python) avec { user_id, notification_type, context_data }. Python génère un titre et un body personnalisés via DeepSeek (1-2 phrases max, ton adapté au rôle). Exemples concrets : au lieu de "Nouveau quiz disponible" → "Ahmed, un quiz calibré sur tes lacunes en dérivées vient d'être généré  8 questions, 15 min." Au lieu de "Rappel : ton abonnement expire" → "Léa, encore 3 jours d'accès Premium. Elle a progressé de 11 points ce mois  c'est le bon moment pour continuer." Cache les messages générés 24h dans Redis ou en mémoire pour les notifications de masse. Rate limit : max 3 notifications personnalisées par utilisateur par jour.
